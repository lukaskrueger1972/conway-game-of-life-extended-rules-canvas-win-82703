## About Conway's Game of Life Extended Rules Canvas

Conway's Game of Life Extended Rules Canvas is an interactive cellular automaton simulation designed for use in a web browser. It provides a visual grid for creating cell arrangements, running generations, and observing how different birth and survival rules shape the simulation.

The project is useful for experimenting with familiar patterns as well as custom rule sets. Built-in examples, editable cells, adjustable speed, and live statistics make it practical for learning, testing patterns, and comparing rules such as Conway, HighLife, and Maze.

---

## Features

- Explore preset patterns including gliders, glider guns, pulsars, and acorns
- Enter custom B/S cellular automaton rules
- Switch quickly between Conway, HighLife, and Maze rules
- Adjust simulation speed from 1 to 30 FPS
- Advance the grid one generation at a time
- Draw cells directly with click-and-drag interaction
- Populate the canvas with randomly placed cells
- View the current generation and live-cell count in real time
